We are building a cloud-based online learning platform for universities and professional training providers with an expected load of around 30,000 monthly active users. The platform will support course enrollment, live and recorded video lectures, assignment submissions, quizzes, and discussion forums, with instructors managing content through an admin dashboard. The system will use a React frontend, a Python Flask backend, and PostgreSQL for persistent data storage, along with object storage for media files, a CDN for efficient content delivery, and centralized monitoring and logging. Key non-functional requirements include scalability, high availability, data security, and cost efficiency. The estimated monthly cloud infrastructure budget for this project is ₹90,000.
